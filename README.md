 🫶 Лепта — платформа добрых сборов

Демо-проект: промо-сайт + полноценное мобильное приложение для сбора пожертвований — для двух сторон: **тех, кто жертвует**, и **тех, кому нужна помощь**.

Человек, которому нужна помощь, выставляет пост: описывает проблему, указывает сумму сбора. Человек, который хочет помочь, видит пост в ленте, нажимает «Пожертвовать» и удобным способом вносит свою лепту.

> ⚠️ Это учебный демо-проект: платежи не списываются, данные хранятся в `localStorage` браузера.

## ✨ Что внутри

**Промо-сайт** (`/`):
- живая бегущая лента пожертвований;
- hero-блок с *настоящим работающим демо* приложения в макете телефона;
- механика «Я хочу помочь / Мне нужна помощь», живые сборы, истории, чек доброты, отзывы, FAQ.

**Мобильное приложение** (`#/app`):
- **Лента сборов** — поиск, фильтры по категориям, рекомендация «почти у цели», живой тикер пожертвований;
- **Экран сбора** — история, новости автора, прогресс; полное пожертвование: сумма → карта/СБП → успех с конфетти;
- **Мастер создания сбора** — категория, история, сумма, срок — и пост сразу в ленте;
- **Мои сборы** — статистика в реальном времени, «Поделиться», «Завершить»;
- **Моя помощь** — история пожертвований с итогами;
- всё сохраняется в `localStorage`, входящие пожертвования симулируются «живой лентой».
